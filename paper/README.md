# The manuscript

*Reconstruction-independent moment tests for sample-based spectral functions*, N. Bonilla Vargas,
prepared for submission to SciPost Physics Core (not yet submitted). It is set in the SciPost submission
class (`SciPost.cls`, 2021-08 version with the PhysCore option; `SciPost_bibstyle.bst`). `main.pdf` is built
from `main.tex` in this folder.

## Structure

| Part | Content | Main data |
|---|---|---|
| Sec. 1 | introduction, five results, relation to the companion, prior art, scope (Tables 1-2) | — |
| Sec. 2 | the moment test, three estimators (shared-state, oracle, bond-basis), Proposition 1 (leak identity), the operator form off an eigenstate | `data/2026-09-27_theory_numerics.json` (`R6_...`) |

Every figure, its generator and its data are listed in [`../docs/REPRODUCE.md`](../docs/REPRODUCE.md)
(Figure → engine → data), and every quoted number family under Key numbers there. `python src/verify.py`
checks the numbers the text prints from four records against their JSON keys.

## Files

- `main.tex` (master), `refs.bib`, `main.bbl` (generated by BibTeX from `refs.bib`), `figstyle.tex` (shared
  figure identity), `main.pdf`.
- `figs/`: native PGFPlots/TikZ fragments (`fig_*.tex`), their data (`*.dat`) and rasters (`*.png`);
  `figs/fig_circuit_qtk.pdf` is compiled from `figs/src/fig_circuit_qtk.tex` (`pdflatex fig_circuit_qtk.tex`).
  `figs/fig_heron.tex` (with `heron_{exact,hw}.dat`) and `figs/fig_teeth.tex` are kept but no longer input by
  `main.tex`: the companion's `L=6` run is described in one paragraph of Sec. 6, and `teeth.dat` is plotted
  inside Fig. teeth_shared.
- `figs/_superseded/`: files no figure reads and the figure files replaced earlier (see its README).
- `SciPost.cls`, `SciPost_bibstyle.bst`: SciPost's template files, under their own terms (see `../LICENSE`).

## Build

```bash
make paper        # from the repository root
# equivalent, from paper/:
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

The build should end with no LaTeX error, no undefined citation or reference and no `??` in the PDF; the
Makefile target checks `main.log` for the first two. The history of the manuscript's earlier versions is in
[`../docs/PROCESS_RECORD.md`](../docs/PROCESS_RECORD.md).
